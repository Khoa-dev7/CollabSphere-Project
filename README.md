# CollabSphere

## 1. Context
In today’s education landscape, the **Project-Based Learning (PBL)** method has become a powerful approach to help students develop practical skills, critical thinking, and teamwork abilities through real-world projects. However, managing and organizing PBL team projects still faces several significant challenges:

*   **Fragmentation**: Students and lecturers often rely on multiple independent platforms for communication, meetings, document sharing, and progress tracking.
*   **Workflow Disruption**: Switching between disjointed tools (e.g., Messenger for chat, Zoom for calls, Trello for tasks, Google Drive for files) reduces efficiency and breaks focus.
*   **Lack of Integration**: Existing platforms are rarely optimized for the specific needs of academic project collaboration, such as integrated grading, peer reviewing, and rubric-based assessment.
*   **Limited Evaluation**: There is often no comprehensive system to track individual contributions accurately or facilitate peer reviews between team members.

Therefore, we propose **CollabSphere**—a unified system designed to streamline project management and real-time collaboration in Project-Based Learning environments. CollabSphere brings together video conferencing, group chat, task boards (Kanban), and file management into one seamless workspace. This system aims to help students and lecturers improve communication, transparently track progress, and create an engaging environment for hands-on learning.

## 2. Proposed Solutions
We are developing a comprehensive web server system with multiple integrated modules to support real-time communication, collaboration, and project development for the Project-Based Learning Method.

### Key Features
*   **Web-App Interface**: Tailored roles for **Admin, Head of Department, Staff, Lecturers, and Students**.
*   **Unified Workspace**: Centralizes communication (Chat, Video), collaboration (File Sharing), and management (Task Board) in one place.
*   **Instructor Support**: Tools for lecturers to guide, monitor, and evaluate student projects with transparent progress tracking, rubrics, and feedback mechanisms.
*   **Student Enablement**: Empowers students to effectively plan, execute, and document their projects through integrated modules:
    *   **Task Board**: Kanban-style task management with drag-and-drop, assignments, and real-time updates.
    *   **Communication**: Real-time text chat and integrated video calling for team meetings.
    *   **File Management**: Easy uploading and sharing of project resources attached directly to tasks.
    *   **Peer Review**: Built-in system for members to evaluate each other’s contributions.
